# Condo Price Calculator

A console pricing exercise for a fictional condominium sales scenario.

## ✨ Highlights

- Park, golf-course, and lake views priced at 150,000, 170,000, and 210,000.
- Optional garage adds 5,000; parking space adds no charge.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "summer.py"
```

Follow the prompts in the terminal.

## 🗂️ Repository guide

- [summer.py](summer.py)

## 📝 Project notes

These are exercise values. Input validation is basic; the parking prompt still runs after an invalid view choice.
